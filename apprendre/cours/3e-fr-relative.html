La proposition subordonnée relative

Un avis de recherche à corriger te sert de fil rouge : à chaque partie, un indice t'aide à trancher entre trois conseils.

Objectifs
  • repérer une subordonnée relative et son antécédent
  • choisir le pronom relatif selon sa fonction dans la relative
  • distinguer relative déterminative et relative explicative
  • corriger les relatives fautives de l'oral

Situation de départ : L'avis de recherche de Radio Bafang

Mama a oublié son sac, avec ses papiers, dans un taxi. Elle dicte à Junior l'avis qu'elle veut faire lire à la radio : « Le taxi que j'ai oublié mon sac dedans était jaune. Le chauffeur que je vous parle est un monsieur gentil. Les papiers que le sac contenait sont importants. Les passagers qui étaient assis derrière peuvent appeler le 6.. »

Le journaliste refuse de lire le texte tel quel. Le grand frère de Junior propose : « Mets “que” partout, c'est plus simple ! »

Document 1 : Ce que demande le journaliste

« Un français correct à l'antenne, et que les auditeurs comprennent bien qui doit appeler : tous les passagers, ou seulement ceux qui étaient assis derrière ? »

Comment corriger l'avis pour que chaque relative soit juste et que le message soit clair ?

Ta tâche : Réécris l'avis de recherche en justifiant le choix de chaque pronom relatif et de la ponctuation.

Les hypothèses à trancher

  1. « Que » convient partout : c'est le pronom relatif le plus courant.
  2. Le pronom relatif se choisit selon sa fonction dans la relative.
  3. Les virgules autour d'une relative ne changent rien au sens.

Reconnaître la relative

La subordonnée relative :

  • commence par un pronom relatif : qui, que, quoi, dont, où, lequel, auquel, duquel… ;
  • complète un nom ou un pronom placé avant elle, appelé antécédent ;
  • joue le rôle d'un adjectif : elle est complément de l'antécédent.
ExempleBanda vend le cacao que sa mère a récolté. — Antécédent : le cacao ; pronom relatif : que.

antécédent + pronom relatif + (sujet) + verbe = subordonnée relative

AntécédentNom ou pronom que la relative complète ; le pronom relatif le représente dans la relative.
Planche 3D : L'antécédent et sa relative, une locomotive et son wagonLa locomotive bleue est l'antécédent (le taxi) ; le wagon orange est la relative (« dans lequel j'ai oublié mon sac »), accrochée par le pronom relatif. Le curseur décroche le wagon : la phrase reste correcte, mais on ne sait plus de quel taxi il s'agit. La manipuler dans Apprendre.
Indice 1

Dans l'avis, chaque passage en italique complète un nom : le taxi, le chauffeur, les papiers, les passagers. Ce sont quatre relatives, et ces quatre noms sont leurs antécédents.

À retenir : Pas d'antécédent, pas de relative : on cherche d'abord le nom complété.

Choisir le pronom relatif

PronomFonction dans la relativeExemple
quisujetl'élève qui parle
queCODle livre que je lis
dontcomplément introduit par « de »l'ami dont je parle (parler de)
oùcomplément de lieu ou de tempsla ville où je suis né ; le jour où il est venu
lequel, auquel…après une prépositionla table sur laquelle j'écris
Fautes fréquentes« L'ami que je t'ai parlé » → l'ami dont je t'ai parlé. « La ville que j'habite dedans » → la ville où j'habite.
La méthode de la phrase simple
  1. Remplace le pronom relatif par l'antécédent et écris la phrase simple : « J'ai oublié mon sac dans le taxi. »
  2. Regarde la fonction du groupe : complément introduit par « dans ».
  3. Choisis le pronom : préposition + lequel → « dans lequel » (ou « où » pour le lieu).
ExemplesLa route où l'accident a eu lieu est en travaux. (lieu)
Le chauffeur dont on parle est prudent. (parler de)
Le car que nous prenons part à 7 h. (COD)
Avec lequelLa gare routière près de laquelle j'habite. · Les passagers auxquels il a parlé.

Simulation interactive : Choisis le bon pronom relatif (dans Apprendre)

Indice 2

« J'ai oublié mon sac dans le taxi » → le taxi dans lequel (ou où) j'ai oublié mon sac. « Je vous parle du chauffeur » → le chauffeur dont je vous parle. « Le sac contenait les papiers » (COD) → les papiers que le sac contenait : ici « que » est juste. Mettre « que » partout produirait deux fautes sur trois.

  • Hypothèse 1 rejetée : « que » n'est correct que pour un COD : « dont » et « dans lequel » sont nécessaires ici.
  • Hypothèse 2 validée : Phrase simple → fonction → pronom.
À retenir : Le pronom dépend de sa fonction DANS la relative : qui sujet, que COD, dont = « de ».

Déterminative ou explicative ?

  • Déterminative : indispensable, elle identifie l'antécédent. Pas de virgule. Les élèves qui ont fini peuvent sortir. (seulement ceux-là)
  • Explicative : on peut la supprimer ; elle ajoute une précision. Entre virgules. Les élèves, qui ont fini, peuvent sortir. (tous ont fini)
Indice 3

Mama veut que seuls les passagers de l'arrière appellent (le chauffeur et le passager avant n'ont rien vu) : la relative doit rester déterminative, sans virgules. Ajouter des virgules changerait le message : les virgules comptent.

  • Hypothèse 3 rejetée : Avec des virgules, la relative devient explicative et désigne tous les passagers.
À retenir : La virgule change le sens : elle transforme une sélection en simple explication.

Situation résolue : L'avis corrigé, prêt pour l'antenne

  1. Repérer les quatre antécédents (indice 1).
  2. Phrase simple → fonction → pronom : où / dans lequel, dont, que (indice 2).
  3. Relative déterminative sans virgules pour « les passagers qui étaient assis derrière » (indice 3).

Avis de recherche corrigé : « Le taxi dans lequel (ou où) j'ai oublié mon sac était jaune. Le chauffeur dont je vous parle est un monsieur gentil. Les papiers que le sac contenait sont importants. Les passagers qui étaient assis derrière peuvent appeler le 6.. » Le pronom se choisit selon sa fonction dans la relative : « dans lequel » ou « où » pour le complément de lieu (oublier dans le taxi), « dont » pour un complément introduit par « de » (parler du chauffeur), « que » pour le COD (contenir les papiers), « qui » pour le sujet. Mettre « que » partout aurait laissé deux fautes. Enfin, la dernière relative reste sans virgules, car elle est déterminative : seuls les passagers de l'arrière sont concernés.

À toi de transférer

Corrige et justifie : « C'est le marché que je t'ai dit que les prix sont bas. » (C'est le marché dont je t'ai dit que les prix sont bas → mieux : C'est le marché où les prix sont bas, dont je t'ai parlé.)

Fiche de révision

  • La relative complète un antécédent (nom ou pronom).
  • Elle commence par un pronom relatif.
  • qui = sujet ; que = COD ; dont = complément en « de » ; où = lieu/temps.
  • lequel, auquel, duquel après une préposition.
  • Déterminative sans virgule ; explicative entre virgules.
  • Méthode : phrase simple → fonction → pronom.
  • Oral fautif : « que … dedans » → dans lequel / où ; « que je te parle » → dont je te parle.

Exercice

Complète avec le bon pronom : 1. Voici la case ___ je suis né. 2. C'est un roman ___ tout le monde parle. 3. Le cacao ___ Banda transporte est lourd. (où ; dont ; que)

Quiz

  1. Dans « le livre que je lis », l'antécédent est…
    Réponse : le livre — Le nom complété par la relative.
  2. « Le chauffeur ___ je vous parle » :
    Réponse : dont — Parler DE quelqu'un.
  3. « Le taxi ___ j'ai oublié mon sac » :
    Réponse : dans lequel — Oublier DANS le taxi (ou « où »).
  4. « Les papiers ___ le sac contenait » :
    Réponse : que — COD de contenait.
  5. « Les passagers ___ étaient assis derrière » :
    Réponse : qui — Sujet de étaient.
  6. Une relative explicative se reconnaît…
    Réponse : à ses virgules — On peut la supprimer.
  7. « Les élèves qui ont fini peuvent sortir » : qui sort ?
    Réponse : seulement ceux qui ont fini — Relative déterminative.
  8. « La ville où je suis né » : « où » est complément…
    Réponse : de lieu — Où = lieu ou temps.
  9. « La table sur ___ j'écris » :
    Réponse : laquelle — Préposition + lequel.
  10. Pour choisir le pronom relatif, on cherche…
    Réponse : sa fonction dans la relative — Méthode de la phrase simple.
