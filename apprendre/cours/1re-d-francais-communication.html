Les conditions de la communication

Un SMS mal compris, un exposé que personne n'écoute, une annonce radio en langue inconnue : la communication échoue souvent. Le linguiste Roman Jakobson a décrit les éléments sans lesquels un message ne passe pas. Les connaître aide à lire les textes… et à mieux se faire comprendre.

Objectifs
  • identifier les six facteurs de la communication
  • associer à chaque facteur sa fonction du langage
  • expliquer les causes d'échec d'une communication

Les six facteurs de la communication

Le schéma de JakobsonUn destinateur (émetteur) adresse un message à un destinataire (récepteur). Pour que le message passe, il faut : un référent (ce dont on parle, le contexte), un code commun (une langue, des signes) et un canal (le contact physique : voix, papier, téléphone, réseau).
ExempleUne mère (destinateur) envoie par WhatsApp (canal), en français (code), à son fils (destinataire) le message « Achète deux kilos de riz au retour » ; le référent est la course à faire.
À retenir : Destinateur, destinataire, message, référent, code, canal.

Les fonctions du langage

À chaque facteur correspond une fonction, selon que le message est centré sur lui :

  • expressive (destinateur) : « Comme je suis heureux ! »
  • conative ou impressive (destinataire) : « Viens ici ! » (impératif, apostrophe)
  • référentielle (référent) : « Yaoundé est la capitale politique. »
  • poétique (message) : jeu sur les sons et les formes, slogans, poèmes
  • métalinguistique (code) : « Que veut dire « mbombo » ? »
  • phatique (canal) : « Allô ? », « Tu me suis ? »
AstuceUn même texte combine souvent plusieurs fonctions ; on cherche la fonction dominante.
À retenir : Expressive, conative, référentielle, poétique, métalinguistique, phatique.

Quand la communication échoue

La communication peut être perturbée par des bruits : tout ce qui gêne la transmission.

  • bruit du canal : réseau coupé, brouhaha du marché, écriture illisible ;
  • bruit du code : langue non partagée, jargon, abréviations de SMS inconnues ;
  • bruit du référent : le destinataire ignore le contexte (une allusion qu'il ne comprend pas) ;
  • bruit psychologique : préjugé, colère, inattention.
La rétroaction (feed-back)La réponse du destinataire permet au destinateur de vérifier que le message est passé et de le corriger.
Le savais-tu ?Avec plus de 250 langues, le Cameroun pratique au quotidien le changement de code : on passe du français à l'anglais, au pidgin ou au camfranglais selon l'interlocuteur.
À retenir : Bruits du canal, du code, du référent ou psychologiques ; la rétroaction permet de corriger.

Entraînement au format de l'examen

Partie A : évaluation des ressources

Question de cours. Dans « Allô, tu m'entends bien ? », la fonction dominante est :

  1. expressive
  2. référentielle
  3. phatique
  4. poétique
Voir la réponse

Phatique : le message vérifie que le contact (canal) fonctionne.

Exercice. Identifie la fonction dominante : a) « Défense d'uriner ici ! » b) « Le mot « nkap » signifie argent. »

Voir la réponse

a) Conative (centrée sur le destinataire, injonction). b) Métalinguistique (porte sur le code).

Partie B : évaluation des compétences

Situation. Le délégué de ta classe à Garoua envoie dans le groupe WhatsApp : « Dvr de maths reporté à jeudi, svp passez l'info ». Plusieurs élèves anglophones et un nouvel élève venu de Maroua n'ont rien compris ; d'autres n'avaient plus de connexion.

Tâche. Analyse cette situation de communication (facteurs, causes de l'échec) et réécris le message pour qu'il soit compris de tous.

Voir une réponse attendue

Destinateur : le délégué ; destinataires : les élèves ; canal : WhatsApp ; code : français abrégé ; référent : le report du devoir. Causes de l'échec : bruit du code (abréviations « dvr », « svp », français seul pour des anglophones) ; bruit du canal (pas de connexion). Message réécrit : « Le devoir de mathématiques est reporté au jeudi 19 novembre. / The maths test is postponed to Thursday, 19 November. Merci de prévenir ceux qui n'ont pas de connexion. » Il faudrait aussi l'annoncer en classe (autre canal) et demander une confirmation (rétroaction).

À retenir : Savoir-être mobilisé : souci d'être compris par tous et respect de la diversité linguistique.

Fiche de révision

  • Six facteurs : destinateur, destinataire, message, référent, code, canal.
  • Fonctions : expressive, conative, référentielle, poétique, métalinguistique, phatique.
  • Chercher la fonction dominante.
  • Bruits : canal, code, référent, psychologiques.
  • La rétroaction vérifie que le message est passé.

Exercice

Pour chaque phrase, donne la fonction dominante : « Ô Afrique, terre de mes ancêtres » ; « Fermez vos cahiers » ; « Le Wouri se jette dans l'Atlantique » ; « Tu me suis ? ». (Expressive ou poétique ; conative ; référentielle ; phatique.)

Quiz

  1. Le schéma de la communication étudié ici est celui de :
    Réponse : Roman Jakobson — Linguiste, 1960 : six facteurs et six fonctions.
  2. Le code désigne :
    Réponse : le système de signes commun — Par exemple une langue.
  3. Le canal est :
    Réponse : le moyen physique de transmission — Voix, papier, téléphone, réseau.
  4. La fonction centrée sur le destinataire est :
    Réponse : conative — Impératif, apostrophe, questions.
  5. « Que signifie le mot « mbombo » ? » relève de la fonction :
    Réponse : métalinguistique — Le message porte sur le code lui-même.
  6. La fonction expressive est centrée sur :
    Réponse : le destinateur — Elle exprime les sentiments de celui qui parle.
  7. Un réseau téléphonique coupé est un bruit :
    Réponse : du canal — Le contact physique est rompu.
  8. La rétroaction (feed-back) permet de :
    Réponse : vérifier que le message est compris — Le destinataire répond au destinateur.
  9. Un slogan publicitaire qui joue sur les sons relève surtout de la fonction :
    Réponse : poétique — Le message est travaillé pour lui-même.
  10. « Yaoundé est la capitale politique du Cameroun » relève de la fonction :
    Réponse : référentielle — Elle informe sur le référent.
