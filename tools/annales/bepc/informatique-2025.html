À l'aide du texte ci-dessus et de vos connaissances, répondre aux questions suivantes :
1. Définir l'expression : influenceur numérique. 1 pt
2. Donner le nom générique attribué aux fausses informations publiées dans les réseaux sociaux. 1 pt
3. Citer deux (02) sanctions auxquelles s'expose cet influenceur numérique. 2 pts
4. Donner deux (02) critères d'une information vraie. 0,5 pt × 2 = 1 pt

PARTIE III : INITIATION À L'ALGORITHMIQUE ET AU DÉVELOPPEMENT LOGICIEL / 7 pts

Exercice 1 : initiation à l'algorithmique (04 pts) — on considère l'algorithme suivant :

1.  Algorithme Montant_Commande ;
2.  Var Quantite, Montant : Entier ;
3.  Début
4.     Ecrire ("Entrer la quantité commandée") ;
5.     Lire (Quantite) ;
6.     Si (Quantité <= 10) alors
7.        Montant ← Quantite*2000 ;
8.     Sinon
9.        Montant ← Quantite*1500 ;
10.    FinSi
11.    Ecrire ("Le montant de votre commande est : ", Montant) ;
12. Fin

Lire attentivement cet algorithme puis répondre aux questions ci-dessous :
1. Identifier dans cet algorithme : a) un type de données ; b) une instruction de sortie de données ; c) une instruction d'affectation ; d) le nom de la structure de contrôle utilisée. 0,5 pt × 4
2. Donner le résultat qui sera affiché à la fin lorsque l'utilisateur fournit la valeur 20 comme quantité commandée. 1 pt
3. Dessiner le symbole d'algorigramme correspondant à la : a) ligne 3 ; b) ligne 9. 0,5 pt + 0,5 pt

PARTIE I

Exercice 1
1. Un bus est un ensemble de fils (liaisons) qui transporte les informations (données, adresses, commandes) entre les composants de l'ordinateur.
2. a) La mémoire stocke les données et les programmes (temporairement pour la RAM, durablement pour les mémoires de masse). b) Le clavier est un périphérique d'entrée qui permet de saisir des caractères et des commandes.
3. Une architecture CISC utilise un jeu d'instructions nombreuses et complexes ; une architecture RISC utilise un jeu réduit d'instructions simples, exécutées plus rapidement.
4. a) Utiliser un régulateur de tension : maintenance préventive. b) Remplacer une barrette mémoire en panne : maintenance corrective (curative).

Exercice 2
1. Un format de données est la manière dont les données sont codées et organisées dans un fichier (exemples : .docx, .jpg, .mp3).
2. a) ASCII : American Standard Code for Information Interchange. b) Un autre code : l'Unicode (UTF-8), l'EBCDIC, le code BCD.
3. Le tableau contient les données structurées ; le paragraphe (texte) contient les données non structurées.
4. p = 111 0000 ; a = 110 0001 ; s = 111 0011 ; s = 111 0011 ; e = 111 0101 (d'après l'extrait donné). Le mot « passe » s'écrit : 1110000 1100001 1110011 1110011 1110101.
Remarque : dans la vraie table ASCII, « e » (code 101) s'écrit 110 0101 ; l'extrait du sujet comporte une coquille, et l'on accepte les deux réponses.

PARTIE II
1. Un influenceur numérique est une personne qui, grâce à sa notoriété et à ses nombreux abonnés sur les réseaux sociaux, peut influencer leurs opinions et leurs comportements.
2. Les fake news (infox, fausses nouvelles).
3. Deux sanctions au choix : une amende ; une peine d'emprisonnement (la loi camerounaise de 2010 sur la cybersécurité et la cybercriminalité punit la publication de fausses nouvelles) ; la suspension ou la fermeture de son compte par le réseau social.
4. Deux critères au choix : la source est connue et fiable (site officiel du ministère) ; l'information est confirmée par plusieurs sources sérieuses ; elle est datée et signée ; elle est vérifiable.

PARTIE III — Exercice 1
1. a) Le type Entier. b) Ecrire ("Le montant de votre commande est : ", Montant) (ou ligne 4). c) Montant ← Quantite*2000 (ou ligne 9). d) La structure alternative (conditionnelle) Si… alors… Sinon… FinSi.
2. Avec 20, la condition 20 <= 10 est fausse : Montant = 20 × 1 500 = 30 000. L'algorithme affiche : « Le montant de votre commande est : 30000 ».
3. a) Ligne 3 (Début) : un ovale (rectangle aux bords arrondis), symbole de début ou de fin. b) Ligne 9 (affectation) : un rectangle, symbole de traitement.

Exercice 2
1. Un langage de programmation est un ensemble de mots et de règles permettant d'écrire des instructions compréhensibles par l'ordinateur, après traduction (exemples : Python, C, Java, Pascal).
2. Deux approches au choix : le cycle en cascade ; le cycle en V ; le cycle en spirale ; les méthodes agiles (itératives).
3. Deux acteurs au choix : le client (maître d'ouvrage) ; le chef de projet ; l'analyste ; le programmeur (développeur) ; le testeur ; l'utilisateur final.
