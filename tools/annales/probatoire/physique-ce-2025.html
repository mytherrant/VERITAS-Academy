PARTIE II : ÉVALUATION DES COMPÉTENCES (16 points)

1. Examinons le résultat du groupe A. Il s'agit de déterminer l'intensité de la pesanteur du lieu afin de se prononcer sur la fiabilité du résultat obtenu. Pour cela, il faut : faire le bilan des forces qui agissent sur le mobile ; utiliser le théorème de l'énergie cinétique pour déterminer l'intensité de la pesanteur ; comparer le résultat à celui des élèves et conclure.
Bilan des forces : la tension \(\overrightarrow{T}\) du fil, la réaction \(\overrightarrow{R}\) du plan incliné, le poids \(\overrightarrow{P}\) du mobile. Notons \(g'\) l'intensité de la pesanteur.
D'après le TEC : \(\Delta E_{c} = W(\overrightarrow{P}) + W(\overrightarrow{R}) + W(\overrightarrow{T})\), soit \(\frac{1}{2}mV^{2} - 0 = P_{1}h + 0 + 0\), avec \(h = ℓ(1 - \cos\theta)\) et \(P_{1} = mg'\sin\alpha\).
Donc \(\frac{1}{2}mV^{2} = mg'\sin\alpha \, ℓ(1 - \cos\theta)\) et \(g' = \frac{V^{2}}{2ℓ\sin\alpha(1 - \cos\theta)} = \frac{0,7^{2}}{2 \times 0,10 \times 0,5 \times 0,5}\) ; \(g' = 9,8\) N/kg.
Comparaison : \(g \ne g'\). Conclusion : le résultat obtenu par le groupe A n'est pas bon.

2. Identification de la nature de l'étoile 71 Tauri. Il s'agit de déterminer la température de cette étoile afin d'identifier sa nature. Pour cela, il faut : déterminer graphiquement la longueur d'onde correspondant à la radiation d'intensité maximale ; exploiter la loi de Wien pour déterminer la température de l'étoile ; la comparer aux valeurs données et conclure.
Graphiquement : \(\lambda_{max} = 470\) nm.
Loi de Wien : \(T = \frac{A}{\lambda_{max}} = \frac{2,89 \times 10^{-3}}{470 \times 10^{-9}}\) ; \(T \approx 6 149\) K, soit \(\theta \approx 5 876\) °C.
Comparaison : la température trouvée est de l'ordre de 5 000 °C. Conclusion : l'étoile 71 Tauri est une étoile froide.

Remarque : dans le corrigé national, la vergence de L2 est obtenue par \(C_{2} = C - \frac{1}{O_{1}F'_{1}}\) ; les applications numériques intermédiaires sont écrites ici pour qu'on puisse vérifier chaque résultat.
