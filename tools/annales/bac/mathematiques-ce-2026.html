Partie B : Évaluation des compétences / 7 points

BALO est le promoteur d'une petite et moyenne entreprise (PME) de fabrication de savons. Lors d'une cérémonie organisée par le Gouvernement, cette PME a été primée pour la qualité de ses produits. Cette PME située dans la région du Nord, voudrait faire la promotion de ses produits dans les trois autres aires culturelles et ceci en langues nationales. Elle a donc recruté autant de commerciaux hommes que de commerciaux femmes. Tous les commerciaux recrutés parlent au moins l'une des 3 langues : Ewondo, Douala et Mendjoumba. Quinze commerciaux recrutés parlent l'Ewondo, vingt parlent le Mendjoumba, dix le Douala, huit parlent l'Ewondo et le Mendjoumba, neuf le Douala et le Mendjoumba et sept parlent le Douala et l'Ewondo.

Lors de la fabrication des savons, de nombreux accidents de travail se produisent conduisant à des blessures. LOBA, le médecin de cette PME veut utiliser les résultats d'une étude fiable sur une hormone secrétée lors de la survenue d'une hémorragie. Cette hormone favorise la réabsorption de l'eau par l'organisme après une hémorragie. Cette étude a modélisé le taux de cette hormone en \(\mu g/ml\) dans le sang en fonction du temps \(t\) en minutes par la fonction \(\varphi\) définie par \(\varphi(t) = 5te^{-\frac{3}{5}t} + 1\). LOBA voudrait connaître le taux maximal de cette hormone contenu dans l'organisme humain.

Pour réduire les coûts d'acquisition de la matière première, BALO a acheté un terrain ayant la forme d'un triangle rectangle pour la culture de cette matière première. Les études faites sur ce terrain ont établi que la production minimale de cette matière première est de 7,5 tonnes à l'hectare et les dimensions de ce terrain sont toutes des nombres entiers naturels. Le côté le plus long de ce terrain mesure \(y\) hm et les deux autres côtés mesurent respectivement \(x\) hm et 6 hm.

Tâches :
1) Déterminer le nombre de commerciaux femmes recrutés dans cette PME. 2,25 pts
2) Déterminer le taux maximal de cette hormone contenue dans l'organisme humain. 2,25 pts
3) Évaluer la production minimale de cette matière première sur le terrain acheté. 2,25 pts
Présentation : 0,25 pt

PARTIE A

Exercice 1
I. 1) \(\overrightarrow{AB}(-1 ; 0 ; 1)\) et \(\overrightarrow{AC}(1 ; 2 ; 1)\) ne sont pas colinéaires : A, B, C ne sont pas alignés et déterminent un plan. Le vecteur \(\overrightarrow{AB} \wedge \overrightarrow{AC} = (-2 ; 2 ; -2)\), soit \(\overrightarrow{n}(1 ; -1 ; 1)\), lui est normal. \(M(x ; y ; z) \in (ABC) \Leftrightarrow \overrightarrow{AM} \cdot \overrightarrow{n} = 0\) : \((ABC) : x - y + z - 2 = 0\) (B et C vérifient bien l'équation).
2) Soit \(\overrightarrow{n}(2 ; -1 ; 2)\) normal à (P), \(\|\overrightarrow{n}\|^{2} = 9\). L'image \(M'\) de \(M\) par la réflexion de plan (P) est \(M' = M - \frac{2(2x - y + 2z - 3)}{9}\overrightarrow{n}\), d'où :
\(x' = \frac{x + 4y - 8z + 12}{9}\) ; \(y' = \frac{4x + 7y + 4z - 6}{9}\) ; \(z' = \frac{-8x + 4y + z + 12}{9}\).
(Vérification : un point de (P), comme \((0 ; -3 ; 0)\), est invariant.)

II. 1) Les colonnes sont les coordonnées de \(\varphi(\overrightarrow{i})\), \(\varphi(\overrightarrow{j})\), \(\varphi(\overrightarrow{k})\) : \(M = \begin{array}{c}1 \quad 0 \quad -1\\ 0 \quad 1 \quad 0\\ -2 \quad 2 \quad 2\end{array}\).
2) \(\varphi(\overrightarrow{u}) = \overrightarrow{0} \Leftrightarrow \begin{cases}x - z = 0\\ y = 0\\ -2x + 2y + 2z = 0\end{cases} \Leftrightarrow y = 0\) et \(z = x\). Ker\(\varphi\) = {\(x(\overrightarrow{i} + \overrightarrow{k})\)} : c'est la droite vectorielle de base \((\overrightarrow{e_{1}})\).
3) Théorème du rang : dim Im\(\varphi\) = 3 − 1 = 2 : Im\(\varphi\) est un plan vectoriel. \(\varphi(\overrightarrow{i}) = \overrightarrow{e_{2}}\) et \(\varphi(\overrightarrow{j}) = \overrightarrow{e_{3}}\) ne sont pas colinéaires : \((\overrightarrow{e_{2}}, \overrightarrow{e_{3}})\) est une base de Im\(\varphi\).
4) \(\det(\overrightarrow{e_{1}}, \overrightarrow{e_{2}}, \overrightarrow{e_{3}}) = \begin{array}{c}1 \quad 1 \quad 0\\ 0 \quad 0 \quad 1\\ 1 \quad -2 \quad 2\end{array} = 1 \times (0 - (-2)) - 1 \times (0 - 1) + 0 = 3 \ne 0\) : c'est une base de E.
5) \(\varphi(\overrightarrow{e_{1}}) = \overrightarrow{0}\) ; \(\varphi(\overrightarrow{e_{2}}) = \varphi(\overrightarrow{i}) - 2\varphi(\overrightarrow{k}) = 3\overrightarrow{i} - 6\overrightarrow{k} = 3\overrightarrow{e_{2}}\) ; \(\varphi(\overrightarrow{e_{3}}) = \varphi(\overrightarrow{j}) + 2\varphi(\overrightarrow{k}) = -2\overrightarrow{i} + \overrightarrow{j} + 6\overrightarrow{k} = -2\overrightarrow{e_{2}} + \overrightarrow{e_{3}}\).
Matrice dans \((\overrightarrow{e_{1}}, \overrightarrow{e_{2}}, \overrightarrow{e_{3}})\) : \(M' = \begin{array}{c}0 \quad 0 \quad 0\\ 0 \quad 3 \quad -2\\ 0 \quad 0 \quad 1\end{array}\).

Exercice 2
I. Notons Bn « beau temps le jour n ». \(P(B_{1}) = \frac{2}{3}\) ; \(P_{B_{n}}(B_{n+1}) = \frac{3}{5}\) et, s'il pleut, \(P(B_{n+1}) = 1 - \frac{2}{3} = \frac{1}{3}\).
1) \(P_{2} = \frac{2}{3} \times \frac{3}{5} + \frac{1}{3} \times \frac{1}{3} = \frac{2}{5} + \frac{1}{9}\) = \(\frac{23}{45}\).
2) \(P_{3} = \frac{23}{45} \times \frac{3}{5} + \frac{22}{45} \times \frac{1}{3} = \frac{317}{675}\) ; probabilité qu'il pleuve le troisième jour : \(1 - \frac{317}{675}\) = \(\frac{358}{675}\).
3) a) Formule des probabilités totales : \(P_{n+1} = \frac{3}{5}P_{n} + \frac{1}{3}(1 - P_{n}) = \frac{4}{15}P_{n} + \frac{1}{3}\).
b) \(Q_{n+1} = \frac{4}{15}P_{n} + \frac{1}{3} - \frac{5}{11} = \frac{4}{15}P_{n} - \frac{4}{33} = \frac{4}{15}\left(P_{n} - \frac{5}{11}\right) = \frac{4}{15}Q_{n}\) : suite géométrique de raison \(\frac{4}{15}\) et de premier terme \(Q_{1} = \frac{2}{3} - \frac{5}{11} = \frac{7}{33}\).
c) \(P_{n} = \frac{5}{11} + \frac{7}{33}\left(\frac{4}{15}\right)^{n-1}\) (on retrouve \(P_{2} = \frac{23}{45}\)).

II. 1) \(z' = x' + iy' = (\sqrt{2} - i\sqrt{6})(x + iy)\) : \(z' = (\sqrt{2} - i\sqrt{6})z\).
2) \(|\sqrt{2} - i\sqrt{6}| = \sqrt{8} = 2\sqrt{2}\) et \(\sqrt{2} - i\sqrt{6} = 2\sqrt{2}\left(\frac{1}{2} - i\frac{\sqrt{3}}{2}\right)\) : S est la similitude directe de centre O, de rapport \(2\sqrt{2}\) et d'angle \(-\frac{\pi}{3}\).
3) \(64x^{2} - 36y^{2} = 576 \Leftrightarrow \frac{x^{2}}{9} - \frac{y^{2}}{16} = 1\) : hyperbole de centre O, d'axe focal (Ox), avec \(a = 3\), \(b = 4\), \(c = \sqrt{a^{2} + b^{2}} = 5\). Excentricité \(e = \frac{c}{a} = \frac{5}{3}\).

Exercice 3
1) \(g'(x) = -1 + e^{x-1}\), négatif sur \(]-\infty ; 1]\), positif sur \([1 ; +\infty[\) : g est décroissante puis croissante, de minimum \(g(1) = 2 - 1 + 1 = 2 \gt 0\). Donc g(x) > 0 pour tout réel x.
2) En \(-\infty\) : \(x - 1 \to -\infty\) et \(e^{1-x} \to +\infty\), donc \(\lim_{x \to -\infty} f(x) = -\infty\). En \(+\infty\) : \((x - 1)e^{1-x} = e \cdot \frac{x - 1}{e^{x}} \to 0\), donc \(\lim_{x \to +\infty} f(x) = +\infty\).
3) \(f'(x) = 1 + e^{1-x} - (x - 1)e^{1-x} = 1 + (2 - x)e^{1-x} = e^{1-x}(e^{x-1} + 2 - x) = g(x)e^{1-x}\). Comme \(g(x) \gt 0\), \(f'(x) \gt 0\) : f est strictement croissante sur ℝ, de \(-\infty\) à \(+\infty\) (\(f(1) = 1\)).
4) En \(+\infty\) : \(f(x) - x = (x - 1)e^{1-x} \to 0\) : la droite \(y = x\) est asymptote oblique ; (C) est au-dessus pour \(x \gt 1\), au-dessous pour \(x \lt 1\). En \(-\infty\) : \(\frac{f(x)}{x} = 1 + \frac{x - 1}{x}e^{1-x} \to +\infty\) : branche parabolique de direction (Oy).
5) \(F'(x) = ae^{1-x} - (ax + b)e^{1-x} = (-ax + a - b)e^{1-x}\). Par identification avec \((x - 1)e^{1-x}\) : \(-a = 1\) et \(a - b = -1\), d'où \(a = -1\), \(b = 0\) : \(F(x) = -xe^{1-x}\).
6) Sur [1 ; 3], f est croissante et \(f(1) = 1 \gt 0\), donc \(f \gt 0\). \(\mathcal{A} = \int_{1}^{3} x\, dx + [F(x)]_{1}^{3} = 4 + (-3e^{-2} + 1)\) = \(5 - \frac{3}{e^{2}} \approx 4,59\) unités d'aire.

PARTIE B

Tâche 1. Notons E, M, D les ensembles des commerciaux parlant l'Ewondo, le Mendjoumba, le Douala, et \(t\) le nombre de ceux qui parlent les trois langues. Tous parlent au moins une langue, donc le nombre total est \(N = 15 + 20 + 10 - 8 - 9 - 7 + t = 21 + t\).
Contraintes : ceux qui ne parlent que le Douala sont \(10 - 9 - 7 + t = t - 6 \ge 0\), donc \(t \ge 6\) ; et \(t \le 7\) (au plus le plus petit des effectifs des intersections). De plus, il y a autant d'hommes que de femmes : N est pair, donc \(t\) est impair.
Ainsi \(t = 7\), \(N = 28\) commerciaux, dont 14 femmes.

Tâche 2. \(\varphi'(t) = 5e^{-\frac{3}{5}t} - 3te^{-\frac{3}{5}t} = (5 - 3t)e^{-\frac{3}{5}t}\), positive pour \(t \lt \frac{5}{3}\), négative après : \(\varphi\) est maximale en \(t = \frac{5}{3}\) min (1 min 40 s).
\(\varphi\left(\frac{5}{3}\right) = \frac{25}{3}e^{-1} + 1 = \frac{25}{3e} + 1\) ≈ 4,07 µg/ml.

Tâche 3. Le terrain est un triangle rectangle d'hypoténuse \(y\) : \(y^{2} = x^{2} + 36\), soit \((y - x)(y + x) = 36\), avec \(x\) et \(y\) entiers naturels, \(y - x \lt y + x\) et ces deux facteurs de même parité (leur somme \(2y\) est paire). Seule la décomposition \(36 = 2 \times 18\) convient (\(6 \times 6\) donnerait \(x = 0\)) : \(y - x = 2\) et \(y + x = 18\), d'où \(x = 8\) hm et \(y = 10\) hm.
Aire : \(\frac{6 \times 8}{2} = 24\) hm² = 24 ha. Production minimale : \(24 \times 7,5\) = 180 tonnes.
