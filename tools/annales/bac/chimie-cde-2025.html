Partie B : ÉVALUATION DES COMPÉTENCES (16 points)

1. Vérifier le titre molaire (8 pt). Démarche : écrire l'équation-bilan du dosage ; trouver le volume de base versé à l'équivalence ; en déduire Ca ; comparer à C ; conclure.
Équation-bilan : AH + HO− → A− + H2O.
\(V_{bE} = 2V_{b\frac{1}{2}} = 2 \times 5 = 10\) mL. À l'équivalence : \(C_{a}V_{a} = C_{b}V_{bE}\), d'où \(C_{a} = \frac{0,2 \times 10}{20} = 0,10\) mol.L−1.
Conclusion : Ca = C, le titre molaire des solutions reçues est exact.

2. Identifier l'acide (8 pt). Démarche : calculer [HO−] ; écrire l'électroneutralité ; en déduire [A−] ; calculer Ka puis pKa ; comparer au tableau.
\([HO^{-}] = \frac{Ke}{[H_{3}O^{+}]} = \frac{10^{-14}}{1,41 \times 10^{-4}} \approx 7,1 \times 10^{-11}\) mol.L−1, négligeable.
Électroneutralité : [Na+] + [H3O+] = [HO−] + [A−], d'où [A−] ≈ [Na+] + [H3O+] = 0,023 + 0,000141 ≈ 0,0231 mol.L−1.
\(Ka = \frac{[H_{3}O^{+}][A^{-}]}{[AH]} = \frac{1,41 \times 10^{-4} \times 0,0231}{0,054} \approx 6,03 \times 10^{-5}\) ; \(pKa = -log (6,03 \times 10^{-5}) \approx 4,2\).
Conclusion : l'acide présent dans les flacons est l'acide benzoïque.
Toute autre méthode juste est acceptée ; un candidat qui résout la tâche sans suivre la démarche obtient tous les points.

Remarques : la transcription du corrigé national donne pH = 6,82 (au lieu de 6,86), situe la question 3 de l'exercice 3 à t = 4,5 min (le sujet dit 5 min) et écrit le pKa comme « −log(6,03 × 10⁻⁶) » ; ces points sont rétablis ici, les résultats (0,15 mol.L⁻¹.min⁻¹ ; pKa = 4,2) étant justes. Le sujet range l'acide cyanhydrique parmi les « acides carboxyliques » : ce n'en est pas un, sans incidence sur la réponse.
