PARTIE A : ÉVALUATION DES RESSOURCES / 10 points

I. Évaluation des savoirs / 4 pts

Exercice 1 : questions à choix multiples (QCM) / 2 pts

Chaque série de propositions comporte une seule réponse exacte (0,5 pt par bonne réponse).

  1. La biodiversité désigne :
    a. le nombre d'arbres d'une forêt ; b. la diversité des espèces vivantes et de leurs milieux ; c. les animaux sauvages seulement ; d. les plantes cultivées.
  2. Dans une chaîne alimentaire, les producteurs sont :
    a. les herbivores ; b. les végétaux chlorophylliens ; c. les carnivores ; d. les décomposeurs.
  3. Le braconnage est :
    a. la chasse autorisée ; b. la chasse illégale d'animaux, souvent protégés ; c. l'élevage ; d. le reboisement.
  4. La réserve de faune du Dja est située :
    a. dans la savane de l'Extrême-Nord ; b. dans la forêt du Sud et de l'Est ; c. sur le littoral ; d. sur le mont Cameroun.
