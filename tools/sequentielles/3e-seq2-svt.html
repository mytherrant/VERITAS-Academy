Exercice 1 : questions à choix multiples (QCM) / 2 pts

Chaque série de propositions comporte une seule réponse exacte. Relève le numéro de chaque question suivi de la lettre de la réponse juste. Réponse juste : 0,5 pt ; réponse fausse ou absence de réponse : 0 pt.

  1. Un virus :
    a. est une cellule complète ; b. se reproduit seul dans l'eau ; c. ne se multiplie qu'à l'intérieur d'une cellule vivante ; d. est visible à l'œil nu.
  2. Les bactéries se reproduisent le plus souvent par :
    a. bourgeonnement ; b. division (scissiparité) ; c. ponte d'œufs ; d. spores uniquement.
  3. Pour observer des levures au microscope optique, on utilise :
    a. une loupe seule ; b. une goutte de culture entre lame et lamelle ; c. un tube à essai fermé ; d. un thermomètre.
  4. Un microbe anaérobie :
    a. a besoin de dioxygène pour vivre ; b. vit sans dioxygène ; c. ne se nourrit pas ; d. est toujours un virus.
