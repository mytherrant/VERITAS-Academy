Base de données (BAC A 2025)« Écrire la requête SQL qui affiche toutes les informations sur les élèves de la Terminale A4 » (en supposant que la table Eleve possède un champ Classe).
SELECT * FROM Eleve WHERE Classe = 'Tle A4';
La clé primaire est le champ qui identifie chaque élève sans doublon : ici, le matricule.

La méthode

  1. Définitions : le terme générique, puis la fonction (« Un onduleur est un appareil qui… »).
  2. Formules, requêtes, programmes : recopie les noms exactement comme dans le sujet.
  3. Algorithmes : déclare les variables et respecte la syntaxe du cours (Début, Fin, Pour, Tant que).
  4. Mises en situation (stage, cybercafé, salle informatique) : nomme le matériel ou le logiciel précis et justifie.

Les erreurs fréquentes

  • Formule sans « = » ou plage mal écrite (B2-F2 au lieu de B2:F2).
  • Oublier les guillemets autour d'un texte dans une requête SQL.
  • Confondre logiciel d'application et système d'exploitation.
  • Trace d'algorithme incomplète : le dernier tour de boucle est souvent oublié.

Check-list du jour J

  • Chaque partie traitée, numéros bien visibles.
  • Formules et algorithmes relus caractère par caractère.
  • Tableaux de trace propres.
  • Pratique : enregistrer souvent, sous le nom demandé.
