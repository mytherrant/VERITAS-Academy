## La règle qui commande toutes les autres

**On n'envoie jamais un message de vente à quelqu'un qui n'a rien demandé.**

Dans un groupe, on publie **une ressource utile et gratuite**. Le lien vers VÉRITAS est en bas, comme une signature — pas comme une offre. On devient la source avant d'être le fournisseur. Un message de pub non sollicité coûte un contact ; une ressource utile en gagne dix.

Trois choses à ne jamais faire :
- diffuser le même message dans dix groupes le même jour ;
- écrire en MAJUSCULES ou empiler les 🔥🔥🔥 ;
- promettre la réussite, une moyenne ou une mention.

**Mise en forme WhatsApp** : `*gras*` · `_italique_` · `~barré~`. Les astérisques sont conservés dans les blocs ci-dessous, copiez-les tels quels.

# D. Réponses aux objections

### #R1 — « C'est trop cher »

```
3 000 FCFA pour toute l'année scolaire, c'est 250 francs par mois.

Et les corrigés des exercices sont gratuits, que vous preniez l'abonnement ou pas. Commencez par eux : si ça ne vous sert pas, vous n'avez rien perdu.
```

### #R2 — « On a une mauvaise connexion à la maison »

```
Ça a été prévu.

L'application Android garde les cours et les exercices sur le téléphone : une fois qu'ils sont chargés, ça fonctionne sans connexion. On se reconnecte seulement pour synchroniser.
```

### #R3 — « Je n'ai pas confiance dans le paiement en ligne »

```
Le paiement se fait par Orange Money ou MTN MoMo, comme un transfert ordinaire. Vous validez sur votre propre téléphone, avec votre code.

Vous recevez un reçu numéroté immédiatement après.

Et si vous préférez ne rien payer en ligne du tout, passez au Centre : on vous inscrit sur place.
```

### #R4 — « Mon enfant va juste recopier les corrigés »

```
C'est le vrai risque, et vous avez raison de le poser.

C'est pour ça que la consigne imprimée dans le cahier est : *cherche d'abord, compare ensuite*. Le corrigé sert à savoir où on s'est trompé, pas à remplir la page.

La façon de vérifier tient en une question : demandez-lui de refaire l'exercice tout seul, le lendemain, sans le corrigé. S'il y arrive, il a appris. S'il n'y arrive pas, il a recopié — et vous le saurez en deux minutes.
```

### #R5 — « Qu'est-ce que vous vendez, exactement ? »

```
Ce qui est gratuit, et qui le restera :
▪️ les 3 932 exercices corrigés (6e → Tle)
▪️ le simulateur de moyenne
▪️ l'essai de Prof. Ambassa

Ce qui se paie, 3 000 à 5 000 FCFA l'année :
▪️ les évaluations corrigées et le suivi des erreurs
▪️ les anciens sujets d'examen avec les corrigés nationaux
▪️ les cours en PDF et en vidéo
▪️ Prof. Ambassa en illimité

Autrement dit : le diagnostic est gratuit, l'entraînement se paie.
```
