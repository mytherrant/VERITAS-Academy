2Le sujet

Cette épreuve étalée sur deux pages, est constituée de deux parties indépendantes.

PARTIE A : Évaluation des ressources (15 points)

Exercice 1 (4 points)

L'unité des longueurs est le centimètre.
ABC est un triangle rectangle en A et de sens direct avec AB = 4.
I est le milieu du côté [BC] et G, le barycentre des points A, B et C affectés respectivement des coefficients 2, 1 et 1.
1) Démontrer que G est le milieu de [AI]. 1 pt
2) Soit (Σ) le lieu des points M du plan tels que \|2MA + MB + MC\| = BC.
Démontrer que (Σ) est un cercle de centre G et passant par A. Faire une figure où on représentera (Σ). 2 pts
3) Déterminer et représenter l'image (Σ') de (Σ) par la rotation r de centre A et d'angle de mesure -π2. 1 pt

Exercice 2 (5 points)

On considère les fonctions numériques f et g à variable réelle définies par les expressions f(x) = -x3 + 3x2 et g(x) = ax3 + bx2 + cx + 4 où a, b et c sont des réels donnés.
Le plan est rapporté au repère orthonormé (O ; i, j). (Cf) est la courbe de f et (Cg), celle de g.
1) Résoudre dans ℝ3, le système d'inconnue (X, Y, Z) suivant : 27X + 9Y + 3Z = 0X + Y + Z = -427X + 6Y + Z = 0 1 pt
2) Déterminer les réels a, b et c sachant que (Cg) coupe l'axe des abscisses au point d'abscisse 1 et admet au point S de coordonnées (3, 4) une tangente parallèle à l'axe des abscisses. 1 pt
3) Dresser le tableau de variation de f et tracer avec soin la courbe (Cf). 2 pts
4) Vérifier que g(x) = f(x - 1). Représenter alors la courbe (Cg). 1 pt

Exercice 3 (3 points)

1) Démontrer que pour tout réel x, on a -2 + cos x < 0. 0,25 pt
2) Démontrer que pour tout réel x, on a -3cos x - 2sin 2x = (1 + 2cos x)(-2 + cos x). 0,5 pt
3) Résoudre alors dans [0 ; 2π[, l'équation -3cos x - 2sin 2x = 0. 1,5 pt
4) Résoudre dans [0 ; 2π[, l'inéquation -3cos x - 2sin 2x > 0. 0,75 pt

PARTIE B : Évaluation des compétences (5 points)

Situation

Kassim a emprunté (sans intérêt) dans une banque de PME, une somme de 20 millions de francs CFA pour un projet d'élevage des chèvres sur une partie de son vaste domaine traversée par une rivière rectiligne. Il doit rembourser cet emprunt en déposant chaque année le même montant dans cette banque. Elle se souvient que le banquier lui avait dit que si elle déposait chaque année 0,5 million de francs CFA de plus, alors sa dette serait épongée 2 ans plus tôt.

La 1re partie du projet consiste à délimiter par une clôture et une bordure de la rivière, une surface rectangulaire d'aire 4,5 ha, comme indiqué la figure ci-dessus où le côté ouvert à l'eau n'a pas besoin de clôture. Les dimensions de cet espace doivent être choisies de telle sorte que la clôture (en pointillés) soit la moins longue possible.

La 2nde partie du projet consiste à creuser la fondation de la clôture et à faire les constructions par la suite. Le technicien en charge des travaux a promis de creuser la fondation sur une longueur de 20,5 m le 1er jour et, pour les autres jours de travail, d'ajouter 1 m sur le nombre de mètres de fondation creusée la veille. Il a aussi promis de garder ce rythme au moins sur une longueur de 600 m de clôture.

Tâches
1) Déterminer le montant de chaque dépôt d'argent dont Kassim a besoin pour éponger sa dette et le nombre de ces dépôts. 1,5 pt
2) Comment choisir les dimensions de l'espace rectangulaire à délimiter pour que la longueur totale de la clôture soit minimale ? 1,5 pt
3) Combien de jours faudra-t-il au technicien pour creuser la fondation sur une longueur de 600 m ? 1,5 pt
Présentation : 0,5 pt

PARTIE A : ÉVALUATION DES RESSOURCES (15 points)

Exercice 1 (4 points)

1) I est le milieu de [BC], c'est-à-dire I = bar{(B ; 1), (C ; 1)}. G = bar{(A ; 2), (B ; 1), (C ; 1)} ; ainsi G = bar{(A ; 2), (I ; 2)}, donc G est le milieu de [AI]. 1 pt

2) \|2MA + MB + MC\| = BC ⇔ \|4MG\| = BC puisque G = bar{(A ; 2), (B ; 1), (C ; 1)}. Ainsi MG = BC4. Donc (Σ) est le cercle de centre G et de rayon BC4.
\|2AA + AB + AC\| = \|AB + AC\| ; or \|AB + AC\|2 = AB2 + AC2 + 2AB · AC = AB2 + AC2 = BC2 car ABC est un triangle rectangle en A. Ainsi \|2AA + AB + AC\| = BC ; donc A ∈ (Σ).
(Σ) est donc le cercle de centre G passant par A. Figure (avec (Σ') de la question 3) : 2 pts

3) (Σ') est le cercle de centre G', image de G par la rotation r, et de même rayon que (Σ). Pour la représentation de (Σ'), voir la figure précédente. 1 pt

Exercice 2 (5 points)

1) 27X + 6Y + Z = 0 ⇒ Z = -27X - 6Y. En substituant Z dans les deux autres équations du système, on obtient 6X + Y = 0 et -26X - 5Y = -4 ; soit X = -1 et Y = 6. Donc X = -1 ; Y = 6 et Z = -9. 1 pt

2) g(x) = ax3 + bx2 + cx + 4 ;
• g(1) = 0, donc a + b + c + 4 = 0 ; soit a + b + c = -4 ;
• g(3) = 4, donc 27a + 9b + 3c + 4 = 4 ; soit 27a + 9b + 3c = 0 ;
• g'(3) = 0, donc 27a + 6b + c = 0.
Donc 27a + 9b + 3c = 0a + b + c = -427a + 6b + c = 0 et d'après la question 1, a = -1 ; b = 6 et c = -9. 1 pt

3) f(x) = -x3 + 3x2.
• Df = ℝ ; limx → -∞ f(x) = +∞ ; limx → +∞ f(x) = -∞.
• f est dérivable sur ℝ et pour tout réel x, f'(x) = -3x2 + 6x.
• f'(x) = 0 équivaut à x = 0 ou x = 2.
• Tableau de variation : 2 pts

f(x)+∞↘0↗4↘-∞

• Courbe représentative (Cf), en trait plein (et (Cg), en tirets, de la question 4) :

4) Soit x un réel, g(x) = -x3 + 6x2 - 9x + 4.
f(x - 1) = -(x - 1)3 + 3(x - 1)2 = -x3 + 3x2 - 3x + 1 + 3x2 - 6x + 3 = -x3 + 6x2 - 9x + 4. Donc g(x) = f(x - 1).
(Cg) est l'image de (Cf) par la translation de vecteur i (voir la figure précédente). 1 pt

Exercice 3 (3 points)

1) Pour tout réel x, -1 ≤ cos x ≤ 1, ainsi -3 ≤ -2 + cos x ≤ -1 < 0 ; donc pour tout réel x, -2 + cos x < 0. 0,25 pt

2) Soit x un nombre réel, -3cos x - 2sin 2x = -3cos x - 2(1 - cos 2x) = 2cos 2x - 3cos x - 2 = (1 + 2cos x)(-2 + cos x). Donc pour tout réel x, -3cos x - 2sin 2x = (1 + 2cos x)(-2 + cos x). 0,5 pt

3) -3cos x - 2sin 2x = 0 ⇔ (1 + 2cos x)(-2 + cos x) = 0, soit 1 + 2cos x = 0 ou -2 + cos x = 0. La seconde est impossible (question 1). Ainsi 1 + 2cos x = 0 ; soit cos x = -12.
Dans ℝ, x = 2π3 + 2kπ ou x = -2π3 + 2kπ, avec k ∈ ℤ.
Dans [0 ; 2π[, x = 2π3 ou x = 4π3. 1,5 pt

Exercice 4 (3 points)

1) M = 0,5 × 10 + 1,5 × 15 + 2,5 × 20 + 3,5 × 20 + 6 × 35100 = 357,5100 = 3,575. Le temps moyen est de 3,575 heures. 0,5 pt

2) Courbe des fréquences cumulées croissantes (fréquences cumulées : 10 ; 25 ; 45 ; 65 ; 100) : 1,5 pt

3) Désignons par me cette médiane. Par interpolation linéaire ou par lecture graphique, on a : me - 350 - 45 = 4 - 365 - 45. Donc me = 3,25. 1 pt

PARTIE B : ÉVALUATION DES COMPÉTENCES (5 points)

Tâche 1. Désignons par n le nombre de dépôts.
• Le montant de chaque dépôt est : 20 000 000n.
• Le montant de chaque dépôt si la dette était épongée 2 ans plus tôt est : 20 000 000n - 2.
• 20 000 000n - 2 = 20 000 000n + 500 000 ; soit 200n - 2 = 200n + 5.
On obtient 5n2 - 10n - 400 = 0 ; soit n2 - 2n - 80 = 0. Δ = 324, n = -8 ou n = 10. Or n est un entier positif, donc n = 10.
• Le montant de chaque dépôt est : 20 000 00010 = 2 000 000.
Donc Kassim effectuera 10 dépôts et le montant de chaque dépôt est de 2 000 000 FCFA.

Tâche 2. Désignons respectivement par x et y la largeur et la longueur en mètres de cet espace rectangulaire ; x > 0 et y > 0.
• Longueur de la clôture : L = 2x + y.
• On a xy = 4,5 ha = 45 000 m² ; donc y = 45 000x. Ainsi L = 2x + 45 000x = 2x2 + 45 000x.
Soit L la fonction qui à x associe L(x) = 2x2 + 45 000x.
• L'(x) = 2 - 45 000x2 = 2x2 - 45 000x2. L'(x) = 0 équivaut à x = 150 car x > 0.
• Tableau de variation :

x0150+∞
L'(x)−0+
L(x)+∞↘600↗+∞

Pour que la longueur totale de la clôture soit minimale (600 m), la largeur doit être égale à 150 m et la longueur égale à y = 45 000150 = 300 ; soit 300 m.

Tâche 3. Désignons par un le nombre de mètres creusés par le technicien le jour de rang n. On a u1 = 20,5 et un+1 = un + 1. (un) est une suite arithmétique de raison 1 et de premier terme u1 = 20,5 ; donc un = 20,5 + (n - 1).
• Désignons par Sn la longueur totale creusée par le technicien au bout de n jours de travail. On a Sn = u1 + u2 + … + un = (u1 + un)n2 = (40 + n)n2.
• Sn = 600 équivaut à (40 + n)n2 = 600 ; soit n2 + 40n - 1 200 = 0. Δ = 6 400 ; n = 20 ou n = -60.
Donc il faudra 20 jours au technicien pour creuser les 600 m.

N.B. : la présentation (0,5 pt) est évaluée sur toute la copie.

Remarques : la longueur AC n'est pas donnée par le sujet ; la figure du corrigé national la prend égale à 3 (d'où BC = 5 et un rayon de 54), ce que reproduit la figure ci-dessus. À l'exercice 3, question 3, l'équation -2 + cos x = 0 n'a pas de solution d'après la question 1, ce que le corrigé national laisse implicite.
