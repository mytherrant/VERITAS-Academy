2Le sujet

L'épreuve est constituée de deux parties indépendantes A et B.

PARTIE A : ÉVALUATION DES RESSOURCES (15 points)
Cette partie est constituée de trois exercices indépendants.

Exercice 1 (5 points)
1. En utilisant la méthode du pivot de Gauss déterminer le triplet de nombres réels (x, y, z) solution du système x + y + z = 15 -x - y + 2z = 0 2x + y - z = 8 1,5 pt
2. On considère p(x) = 2x3 - 3x2 - 17x + 30.
a) Montrer que pour tout x dans ℝ, p(x) = (x - 2)(2x2 + x - 15). 0,75 pt
b) Résoudre dans ℝ l'équation : p(x) = 0. 0,75 pt
c) Résoudre dans ℝ l'équation : 2(ln x)3 - 3(ln x)2 - 17(ln x) + 30 = 0. 1 pt
d) Résoudre dans ℝ l'équation : 2e6x - 3e4x - 17e2x + 30 = 0. 1 pt

Exercice 2 (4 points)
Une entreprise camerounaise veut lancer sur le marché un nouveau logiciel de gestion. Elle demande à un cabinet de réaliser une étude sur :
• le prix xi en euros d'une unité de logiciel ;
• la demande yi en centaines d'unités de logiciel dans le pays.
Cette étude a été réalisée dans 6 pays africains convenablement choisis parmi lesquels se trouve le Cameroun. Voici les résultats :

xi5055607085100
yi327315300271255200

1) Trouver les coordonnées du point moyen G. 1 pt
2) Montrer qu'une équation cartésienne de la droite de Mayer est : y = -2,4x + 446. 1,5 pt
3) En utilisant l'équation précédente, donner une estimation du prix unitaire pour une demande de 400 centaines d'unités dans un pays. 0,5 pt
4) On choisit au hasard deux pays parmi les six pour représenter l'Afrique à Bruxelles lors d'une conférence sur la gestion des politiques économiques. Calculer la probabilité que le Cameroun soit compté parmi les deux pays choisis. 1 pt

Exercice 3 (6 points)
Soit f une fonction de IR dans IR définie sur D = ]0 ; +∞[ par f(x) = 1x + ln x. On appelle (C) sa courbe représentative dans le plan muni du repère orthonormé (O, I, J). Unité sur les axes : 1 cm.
1) a) Montrer que pour tout x ∈ D, f(x) = 1x(1 + xln x), puis en déduire la limite de f à droite de 0. 0,5 pt
b) Calculer la limite de f en +∞. 0,25 pt
2) Montrer que (C) admet une asymptote verticale que l'on précisera. 0,25 pt
3) a) Pour tout x de ]0 ; +∞[, calculer f'(x) et vérifier que f'(x) = x - 1x2. 0,75 pt
b) Dresser le tableau des variations de f. 0,75 pt
4) Calculer f(0,25), f(0,5), f(2) et f(3). 1 pt
5) Construire (C) et son asymptote. 1,5 pt
6) a) Soit h la fonction définie sur ]0 ; +∞[ par h(x) = (x + 1)ln x - x. Calculer h'(x). 0,5 pt
b) En déduire les primitives de f sur ]0 ; +∞[. 0,5 pt

PARTIE B : ÉVALUATION DES COMPÉTENCES (5 points)

Situation
Une entreprise a prévu dépenser une somme de 7 500 000 FCFA pour payer ses employés à la fin de la réalisation d'un projet. Cette somme devra être partagée équitablement aux employés. À la fin du projet, l'entreprise constate que seuls les deux tiers des employés présents au début ont réellement travaillé. Chaque employé ayant travaillé voit alors sa part augmentée de 250 000 FCFA.
Monsieur Abel, employé ayant travaillé dans cette entreprise aimerait placer une partie de son salaire dans une banque dont il a oublié le taux d'intérêt annuel. Un gestionnaire de comptes de cette banque lui explique que, s'il plaçait 500 000 FCFA dans un compte bloqué, il retirerait 583 200 FCFA au bout de 2 ans (intérêts composés).
Monsieur Abel possède par ailleurs un champ rectangulaire d'aire 9 600 m², dont la longueur dépasse la largeur de 40 m. Il entoure ce champ d'un grillage qu'il achète à 1 000 000 FCFA.

Tâches
1) Déterminer le montant reçu par chaque ouvrier à la fin des travaux. 1,5 pt
2) Déterminer le taux d'intérêt de la banque. 1,5 pt
3) Déterminer le prix du mètre de grillage utilisé. 1,5 pt
Présentation : 0,5 pt

3Le corrigé

Afficher le corrigé (après avoir traité le sujet)
Corrigé harmonisé national. Grille officielle utilisée par les correcteurs ; toute réponse pertinente non prévue est prise en compte.

PARTIE A : ÉVALUATION DES RESSOURCES (15 points)

Exercice 1 (5 points)
1. On range les équations : (E1) : x + y + z = 15, (E2) : 2x + y - z = 8, (E3) : -x - y + 2z = 0.
-2(E1) + (E2) donne (E2') : -y - 3z = -22 ; (E1) + (E3) donne (E3') : 3z = 15.
Le système est équivalent à x + y + z = 15 -y - 3z = -22 3z = 15, d'où z = 5, puis y = 22 - 15 = 7, puis x = 15 - 7 - 5 = 3. La solution est (3 ; 7 ; 5).
2. a) (x - 2)(2x2 + x - 15) = 2x3 + x2 - 15x - 4x2 - 2x + 30 = 2x3 - 3x2 - 17x + 30 = p(x).
b) p(x) = 0 ⇔ x - 2 = 0 ou 2x2 + x - 15 = 0. Pour le trinôme, Δ = 1 + 120 = 121 = 112, d'où x = -1 - 114 = -3 et x = -1 + 114 = 52. S = {-3 ; 2 ; 52}.
c) L'équation n'a de sens que pour x > 0. En posant a = ln x, elle s'écrit p(a) = 0, donc ln x = -3, ln x = 2 ou ln x = 52. S = {e-3 ; e2 ; e52}.
d) En posant b = e2x (b > 0), l'équation s'écrit p(b) = 0. La racine -3 est exclue car b > 0 ; il reste e2x = 2 ou e2x = 52. S = {ln 22 ; ln 2,52}.

Exercice 2 (4 points)
1) x = 50 + 55 + 60 + 70 + 85 + 1006 = 4206 = 70 et y = 327 + 315 + 300 + 271 + 255 + 2006 = 1 6686 = 278. G(70 ; 278).
2) Points moyens des deux sous-nuages (trois premiers et trois derniers pays) : G1(1653 ; 9423) = G1(55 ; 314) et G2(2553 ; 7263) = G2(85 ; 242).
Pente : a = 242 - 31485 - 55 = -7230 = -2,4 ; ordonnée à l'origine : b = 314 + 2,4 × 55 = 446. La droite de Mayer (G1G2) a pour équation y = -2,4x + 446.
3) Pour y = 400 : x = 400 - 446-2,4 = 462,4 ≈ 19,17. Le prix unitaire estimé est d'environ 19,17 euros.
4) Il y a C62 = 15 choix possibles ; ceux qui contiennent le Cameroun sont C11 × C51 = 5. La probabilité est 515 = 13.

Exercice 3 (6 points)
1) a) Pour x > 0 : 1x(1 + xln x) = 1x + ln x = f(x). Quand x → 0+, xln x → 0, donc 1 + xln x → 1, et 1x → +∞ : limx → 0+ f(x) = +∞.
b) limx → +∞ 1x = 0 et limx → +∞ ln x = +∞, donc limx → +∞ f(x) = +∞.
2) Puisque limx → 0+ f(x) = +∞, la droite d'équation x = 0 (l'axe des ordonnées) est asymptote verticale à (C).
3) a) f'(x) = -1x2 + 1x = -1 + xx2 = x - 1x2.
b) x2 > 0, donc f'(x) a le signe de x - 1 : négatif sur ]0 ; 1[, nul en 1, positif sur ]1 ; +∞[. f(1) = 1 + ln 1 = 1.

5) Courbe (C) et son asymptote (l'axe des ordonnées) :

6) a) h'(x) = 1 × ln x + (x + 1) × 1x - 1 = ln x + 1 + 1x - 1 = 1x + ln x, soit h'(x) = f(x).
b) h est donc une primitive de f sur ]0 ; +∞[. Les primitives de f sur cet intervalle sont les fonctions x ↦ (x + 1)ln x - x + c, où c est une constante réelle.

PARTIE B : ÉVALUATION DES COMPÉTENCES (5 points)

Tâche 1. Soit n le nombre d'employés présents au début (n multiple de 3). Seuls 2n3 ont travaillé, et chacun reçoit 250 000 FCFA de plus que la part prévue :
7 500 0002n3 = 7 500 000n + 250 000 ⇔ 11 250 000n - 7 500 000n = 250 000 ⇔ 3 750 000n = 250 000 ⇔ n = 15.
Dix employés ont travaillé ; chacun a reçu 7 500 00010 = 750 000 FCFA (la part prévue, 500 000 FCFA, augmentée de 250 000 FCFA).

Tâche 2. Soit t % le taux annuel. Avec les intérêts composés, au bout de 2 ans : 500 000(1 + t100)2 = 583 200, soit (1 + t100)2 = 1,1664 = 1,082.
Comme 1 + t100 > 0 : 1 + t100 = 1,08, d'où t = 8. (En développant, on retrouve l'équation t2 + 200t - 1 664 = 0, de racines 8 et −208.) Le taux d'intérêt est de 8 %.

Tâche 3. Soit x la longueur et y la largeur du champ (en m) : xy = 9 600 et x - y = 40. Alors x(x - 40) = 9 600, soit x2 - 40x - 9 600 = 0 ; Δ = 1 600 + 38 400 = 40 000 = 2002, d'où x = 40 + 2002 = 120 (l'autre racine, −80, est exclue) et y = 80.
Longueur du grillage (périmètre) : 2(120 + 80) = 400 m. Prix du mètre : 1 000 000400 = 2 500 FCFA.

Remarques : la transcription en ligne du corrigé national omet la question 6 de l'exercice 3, rédigée ici. Pour la tâche 1, elle pose une équation d'inconnue « n + 5 » et la « simplifie » en 5n2 - 75n = 0, ce qui ne correspond à aucun calcul ; la démarche est refaite (le résultat, 750 000 FCFA, est juste). Elle arrondit enfin 19,166… à 19,16 au lieu de 19,17.
