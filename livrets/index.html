Mon Cahier de français — en ligne

Le livret d'activités, tel quel, mais dans le navigateur : l'élève écrit ses réponses, coche, relie, remplit les grilles — et découvre la correction exercice par exercice, quand il l'a cherchée.

Comment ça marche ? Un code d'accès par classe, valable toute l'année scolaire, utilisable sur 3 appareils (le téléphone de l'élève et l'ordinateur de la maison, par exemple). Les réponses saisies restent sur l'appareil ; la correction, elle, vient du serveur.

Choisir sa classe

1 500 FCFA par classe, pour l'année scolaire. Paiement par Orange Money, MTN MoMo ou carte bancaire — le code d'accès est délivré dès que le paiement est confirmé.

Obtenir son code en trois étapes

  1. Ouvre le livret de ta classe, puis clique sur « Je n'ai pas de code — obtenir l'accès ».
  2. Paie 1 500 FCFA avec ton numéro Orange Money ou MTN MoMo (ou par carte).
  3. Le code s'affiche tout seul dès la confirmation, et le livret s'ouvre. Note-le : il te resservira sur tes autres appareils.

Code perdu ? Rouvre le livret, clique sur « obtenir l'accès » puis « J'ai déjà payé — retrouver mon code » : il te faudra la référence du paiement et les 4 derniers chiffres du numéro payeur.

Le livret en ligne remplace-t-il le cahier ?

Non — il le prolonge. Le cahier imprimé reste le support de travail en classe et à la maison ; la version en ligne sert à s'entraîner ailleurs, à vérifier une correction, et à ne pas perdre son travail. Les corrigés des cahiers, eux, restent gratuits et accessibles à tous.
