Pourquoi un code ? Le Guide pédagogique contient les corrigés complets, les barèmes et la conduite de classe. Son exclusivité fait sa valeur : un élève ne doit pas y entrer. Chaque ouverture de ressource est journalisée et un code se révoque en une minute. Les élèves, eux, ont leur propre espace — libre et gratuit.

Entrer avec mon code enseignant

Le code vous est remis à l'adoption des cahiers, par le Centre VÉRITAS. Il est valable pour l'année scolaire.

Pas encore de code ? Le demander par WhatsApp (réponse sous 2 h, jours ouvrés) ou écrire à contact@veritas-school.com.

Mes ressources

Les documents s'ouvrent en téléchargement direct. Session ouverte pour 8 heures.

Ce que contient l'espace

Le Guide pédagogique

Un guide par niveau : corrigés complets de tous les exercices, conduite de la classe, barèmes, remédiation.

Grilles d'évaluation MINESEC

Les grilles officielles harmonisées, par type d'épreuve, avec les critères et leur pondération.

Progressions annuelles

La répartition séquence par séquence, semaine par semaine, alignée sur le programme.

Épreuves à photocopier

Devoirs et évaluations séquentielles, avec leurs corrigés et leurs barèmes.

Ce que voient vos élèves

Les élèves accèdent librement aux corrigés des exercices du cahier — c'est ce que promet l'encadré imprimé dans leur cahier, et c'est volontaire : le corrigé est masqué tant qu'ils n'ont pas cliqué, l'effort vient d'abord. Ce qui reste exclusivement dans votre Guide : la conduite de classe, les barèmes détaillés, les productions modèles commentées et les notes de remédiation.
